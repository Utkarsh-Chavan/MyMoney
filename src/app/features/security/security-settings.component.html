Export encrypted backup

Download a portable, password-encrypted copy of your local data.

Keep the backup passphrase safe. It is not stored by MyMoney and cannot be recovered. Losing it means the backup cannot be decrypted. The device-local application lock is intentionally not exported; database settings and your theme preference are included.

Backup files use the .mmbak extension. The browser does not reliably report when or where a download is saved, so MyMoney does not display a last-backup date.
